# J.S. Handloom

A website for J.S. Handloom, showcasing handcrafted sarees and textiles.

## About

J.S. Handloom is a traditional handloom store offering a curated collection of handwoven sarees and fabrics. This site serves as the online presence for the brand, featuring product showcases, an about page, and a coming-soon section for new arrivals.

## Structure

```
├── index.html          # Home page
├── about-us.html       # About the brand
├── coming-soon.html    # New arrivals / coming soon page
├── images/             # All image assets
├── styles/             # CSS stylesheets
└── scripts/            # JavaScript files
```

## Deployment

This site is deployed to GitHub Pages via GitHub Actions on every push to `main`.

Live site: [https://swapnadeep2k.github.io/J.S.HANDLOOM/](https://swapnadeep2k.github.io/J.S.HANDLOOM/)
