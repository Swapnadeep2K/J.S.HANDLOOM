# J.S. Handloom

A website for J.S. Handloom, showcasing handcrafted sarees and textiles.

## About

J.S. Handloom is a traditional handloom store offering a curated collection of
handwoven sarees and fabrics. This site serves as the online presence for the
brand, featuring a product catalog with WhatsApp-based enquiry (no accounts,
no payment), an about page, and product showcases.

## Structure

Source files (edit these):

```
├── index.html            # Home page
├── about-us.html         # About the brand
├── shop.html             # Product catalog
├── coming-soon.html      # Redirects old links to shop.html
├── partials/             # Shared header / footer / support-widget markup
│   ├── header.html
│   ├── footer.html
│   └── support-widget.html
├── data/
│   └── products.json     # The product catalog - edit this to add/change products
├── images/
│   └── products/         # Product photos (currently placeholder SVGs - replace with real photos)
├── styles/
│   └── tokens.css         # Brand colors as CSS variables - change these to restyle the whole site
├── scripts/
│   └── build.js           # The build script (see below)
└── .github/workflows/deploy.yml
```

`dist/` is generated by the build and is not committed (add it to `.gitignore`
if it isn't already).

## How the build works

Every source `*.html` file in the repo root contains include markers instead
of duplicated header/footer markup:

```html
<!--#include header-->
...
<!--#include footer-->
<!--#include support-widget-->
```

`shop.html` and `index.html` also contain a products marker:

```html
<!--#products-->          <!-- all products -->
<!--#products limit=6-->  <!-- first 6 products -->
```

and `shop.html` contains a category filter marker:

```html
<!--#category-filters-->
```

Running `node scripts/build.js` reads `partials/*.html` and
`data/products.json`, replaces those markers, and writes the finished static
HTML into `dist/`, alongside a copy of `styles/`, `scripts/`, and `images/`.
That's what actually gets deployed — the root `*.html` files are the
authoring format, not the served files.

To preview locally:

```
npm run build
npm run preview
```

(equivalent to `node scripts/build.js` then serving `dist/` with any static
file server — there are no npm dependencies, `package.json` just gives the
two commands a name.)

## Adding or editing products

Edit `data/products.json`. Each entry:

```json
{
  "id": "unique-slug",
  "name": "Display name",
  "category": "Category label shown on the site",
  "categorySlug": "url-safe-category-slug",
  "description": "One line, shown on the card.",
  "price": "Price on enquiry",
  "image": "images/products/your-photo.jpg",
  "whatsappMessage": "Pre-filled text sent when a visitor taps Enquire."
}
```

New `categorySlug` values automatically get their own filter chip on the shop
page — no other file needs to change.

## Deployment

This site is deployed to GitHub Pages via GitHub Actions on every push to
`main`. The workflow runs `node scripts/build.js` and deploys the resulting
`dist/` folder — no separate hosting or database needed.

Live site: [https://swapnadeep2k.github.io/J.S.HANDLOOM/](https://swapnadeep2k.github.io/J.S.HANDLOOM/)
